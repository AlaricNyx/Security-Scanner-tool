## 🛡️ Overview

**Alaric Nyx Security Scanner** is a defensive network security tool developed using **Python and Nmap**.

The purpose of this project is to perform authorized network analysis, identify open ports, detect running services, and understand basic security assessment workflows.

This tool was created for cybersecurity learning, SOC practice, and defensive security research.

---

# 🚀 Features

✅ Port Scanning  
✅ Service Detection  
✅ Version Detection  
✅ Network Analysis  
✅ Basic Security Assessment  
✅ Terminal Based Interface  
✅ Fast Scan Results

# ⚙️ Installation

## 1. Clone Repository

```bash
git clone https://github.com/AlaricNyx/Security-Scanner-tool.git
```

## 2. Enter Directory

```bash
cd Security-Scanner-tool
```

## 3. Install Requirements

```bash
pip install -r requirements.txt
```

---

# ▶️ Usage

Run the scanner:

```bash
python scanner.py
```

Enter an authorized target IP address when requested.

Example:

```
Enter Authorized Target IP:

127.0.0.1
```
